## ✨ Features

- 📱 **Fully Responsive** — Looks great on all devices, from mobile to desktop.
- 🎞️ **Smooth Animations** — Powered by [Framer Motion](https://www.framer.com/motion/) for elegant scroll and entrance effects.
- 🧩 **Interactive Elements** — Animated counters, mobile hamburger menu, and call-to-action buttons.
- ⚡ **Blazing Fast** — Built with Vite for near-instant dev server startup and HMR.
- 🛡️ **Type Safe** — Written entirely in TypeScript for better maintainability and fewer bugs.
- 🎨 **Utility-First CSS** — Tailwind CSS with `clsx` and `tailwind-merge` for clean, maintainable styling.
- 🖼️ **Icon Library** — [Lucide React](https://lucide.dev/) for crisp, scalable icons.
